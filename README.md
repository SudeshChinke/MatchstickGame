# 🎮 Matchstick Game

A simple web-based Matchstick Game built using **HTML, CSS, JavaScript, and Tailwind CSS**.

## 📝 Rules
- The game starts with **21 matchsticks**.
- Each player can pick **1 to 4 matchsticks** per turn.
- The computer plays strategically.
- The player who picks the **last matchstick loses**.

## ✨ Features
- Interactive gameplay
- Responsive design
- Computer AI opponent
- Reset game option
- Built with HTML, CSS, JavaScript, and Tailwind CSS

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Tailwind CSS

## 🚀 How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/SudeshChinke/MatchstickGame.git
   ```

2. Open the `game.html` file in your web browser.
